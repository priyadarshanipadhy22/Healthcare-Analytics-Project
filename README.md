# 🏥 Healthcare Analytics Project

An end-to-end Healthcare Analytics project designed to analyze patient admissions, hospital performance, revenue, surgeries, and financial performance using Python, MySQL, Excel, and Power BI.

## 📌 Project Overview

This project demonstrates a complete healthcare data analytics workflow, starting from raw healthcare data generation and data cleaning to exploratory data analysis, SQL business analysis, and interactive Power BI dashboards.

## 🎯 Objectives

* Clean and preprocess healthcare data
* Perform exploratory data analysis using Python
* Analyze patient and hospital performance
* Perform business analysis using MySQL
* Analyze healthcare revenue and payment patterns
* Build interactive Power BI dashboards
* Generate actionable healthcare insights

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* MySQL
* Excel
* Power BI
* Git & GitHub

## 📊 Power BI Dashboard

### 1. Executive Summary

The Executive Summary provides an overview of healthcare operations through key performance indicators and monthly trends.

Key metrics include:

* Total Patients
* Total Revenue
* Total Amount Paid
* Average Feedback Rating
* Average Hospital Stay
* Total Surgeries
* Monthly Patient Trend
* Monthly Revenue Trend
* Patients by Disease

### 2. Hospital Performance

This page focuses on hospital and patient performance.

Analysis includes:

* Disease Distribution
* Patients Requiring Surgery
* Average Hospital Stay by Disease
* Top Doctors by Patients Treated

### 3. Financial Analysis

This page focuses on healthcare financial performance.

Analysis includes:

* Revenue by Payment Mode
* Revenue by Department
* Pending Amount by Department
* Top 10 Patients by Total Bill
* Revenue by Disease

## 🔍 Key Insights

* Identified diseases with the highest number of patient admissions.
* Analyzed monthly patient admission trends.
* Compared monthly hospital revenue.
* Evaluated department-wise revenue performance.
* Analyzed disease distribution across patients.
* Compared revenue generated through different payment methods.
* Measured average hospital stay by disease.
* Identified doctors treating the highest number of patients.
* Analyzed pending hospital amounts by department.
